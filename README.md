# CIFAR-10-Image-Classification-using-CNN
This project uses a Convolutional Neural Network (CNN) to classify images from the CIFAR-10 dataset. It demonstrates the complete deep learning workflow, including image preprocessing, model training, and performance evaluation.

•	Built a Convolutional Neural Network (CNN) using PyTorch to classify images from the CIFAR-10 dataset into 10 object classes.

•	Prepared image data using Torchvision, normalization, and DataLoaders for model training. 

•	Evaluated the CNN model using classification accuracy after training with the Adam optimizer and CrossEntropy Loss.
